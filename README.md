# Projeto-5-App_Day_Trade_Analytics_Tempo_Real_com_Agentes_de_IA
O objetivo é entregar uma plataforma robusta, integrada com Agentes de IA e infraestrutura em nuvem da AWS. Essa solução proverá um módulo de Analytics em tempo real e um módulo de IA recomendando oportunidades assertivas e automatizando o suporte às decisões financeiras
